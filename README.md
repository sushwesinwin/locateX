# LocateX

A modern web application built with React, TypeScript, and Leaflet for location tracking.

## Features

- Add, edit, and delete locations
- View locations on a map
- Filter locations by name or description
- Sort locations by name, latitude, or longitude

## Technologies Used

- React
- TypeScript
- Leaflet
- Redux
- React-Leaflet
- React-Hook-Form
- Vite

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (comes with Node.js) or yarn
